# South Sudan Sales Performance Dashboard

## Overview

This project analyzes sales performance using Power BI.

## Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Customers KPI
- Monthly Sales Trends
- Sales by State
- Product Analysis
- Customer Analysis

## Tools Used

- Power BI Desktop
- Microsoft Excel
- DAX
